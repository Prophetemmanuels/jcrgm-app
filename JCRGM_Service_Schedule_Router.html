1. Church Leaders / Pastors

The moment a name is added it is placed into one of the four service groups automatically, so one person serves on one group's Sunday only — never two groups on the same day.

Shuffle Groups re-deals the same names into new groups. Nobody is removed.

2. Group Rotation

Two ways to staff a Sunday

All Pastors — one name per duty (recommended). Every service is staffed from the whole pastor list, one name per responsibility. No pastor is tied to a group, so any pastor can serve on any Sunday, and the router simply keeps names from repeating the same duty.

Group Rotation. The month is split into four groups: 1st Sunday Group 1, 2nd Sunday Group 2, 3rd Group 3, 4th Group 4, and a 5th Sunday back to Group 1. Each group leads both the morning and the afternoon service on its own Sunday, so no two groups ever clash.

In both modes:
• one pastor never holds two duties in the same service;
• the same name is not put on the same duty twice;
• every registered pastor is scheduled;
• a Friday is led by the group taking that week's Sunday (or drawn from all pastors in All Pastors mode).
