Important operating notes

  • Save drafts before closing a page or changing devices. Unsaved text lives only in the current tab. Exam answers also auto-save while online; the server deadline uses the last saved work at expiry.
  • Updates refresh approximately every 20 seconds while the page is open. No SMS, WhatsApp or background push notifications are included.
  • Files: PDF/JPG/PNG, up to 5 MB each; 200 reservations / 100 MB per student, subject to your provider quota. No automatic virus scanning is provided.
  • Private download links expire after 60 seconds. Do not share them. Access revocation cannot retrieve already downloaded or printed information.
  • Old records can be submitted through My record for manual review. Local marks, fee flags and certificate seals are not automatically trusted.
  • The old offline file included formal answers. Prior downloads or Git history may still expose them. Replace/rotate assessment questions before relying on secrecy for high-stakes examinations.
  • Certificates are recorded in the server register. Generated PDFs are not digitally signed; verify certificate numbers with the registrar.
  • Back up database records and storage objects, and monitor Supabase/email/storage limits. Read BIBLE-SCHOOL-README.md in the package for the complete operating notes.
