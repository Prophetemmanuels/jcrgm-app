JCRGM — Programme Preparations & Guidance
========================================

INSTALL THE UPDATE
1. Back up your current index.html.
2. Extract this ZIP.
3. Put index.html and programme-preparations.html in the SAME folder as your
   existing church website pages. Replace your old index.html with this one.
4. Keep your existing ministry-workers.html, permits-invitations.html and all
   other website pages. They are not replaced by this package.
5. Open index.html. Under Giving & Events, press "programme preparations".

The index was updated from the latest version in this conversation, keeping
its existing content and the Permits & Invitations and Ministry Workers links.

WHAT IS INCLUDED
- 10 preparation templates: general, all-night, worship service, conference,
  outreach, youth/children, retreat/camp, crossover, wedding and memorial.
- 83 core preparation tasks plus the selected type's specialist tasks.
- Guidance across 12 preparation areas and five planning phases.
- Task owners, deadline overrides, notes, critical tasks, custom tasks,
  progress tracking and not-applicable reasons.
- Programme setup, overnight/multi-day run sheet, team assignments,
  budget/actual costs, attendance, private follow-up and review notes.
- Six coordinated colour themes and embedded SVG icons.
- Your church logo on the workspace and downloadable checklists.

PREPARATION WORKFLOW
1. Open Programme setup. Select a type and press Apply programme type.
2. Enter the programme name, date, start/end times, venue and coordinator.
   Enter the NEXT DAY as the end date for an overnight programme.
3. Review Guidance and assign checklist owners and deadlines.
4. Prepare the Run sheet and Teams. Check critical tasks with accountable leaders.
5. Press Save plan to retain your work in this browser. Saving is manual.
6. Use Downloads to print or download the checklist for your team.

CHECKLIST DOWNLOADS AND PRINTING
Downloads offers:
- PDF: a direct, selectable-text A4 PDF with church logo and page numbers.
- CSV: selected checklist tasks for a spreadsheet.
- Print checklist: a clean handout without app controls.
- Current progress or a blank working copy for handwriting.
- Complete checklist, one area, one phase or the current checklist filters.
- Optional guidance and task notes.

Print settings: A4, 100% scale, browser headers and footers OFF.
The Run sheet has a separate Print / Save as PDF handout.

PREPARATION DATES AND PROGRESS
Dates and programme times are treated as Zambia time (UTC+02:00).
Suggested preparation deadlines follow the programme start date. Close-out
uses the end date when entered. Override individual task dates as needed.
After-programme tasks are excluded from pre-programme completion percentages.
Not-applicable tasks require a reason and are excluded from applicable totals.
Completion percentages do NOT represent safety certification or legal approval.
A responsible leader must review critical tasks and actual conditions.

SAVING, PRIVACY AND BACKUPS
Only one working programme is stored under the new browser-save key.
- Save plan: saves the current plan in this browser on this device.
- Download plan backup: saves a JSON file containing ALL plan information.
- Import plan backup: restores a compatible JSON backup after confirmation.
- New programme: starts fresh working data, leaving the prior browser save
  intact until you choose to save the new plan.
- Delete browser save: removes only the stored copy, not downloaded backups.

Private follow-up, finance, emergency contacts, team contacts and leadership
notes are excluded from ordinary checklist exports. Task owners and programme
coordinator names are included in current-progress checklists. Review task
notes before choosing to include them in a shared document.

Complete JSON backups DO include private records. Keep them secure and do not
save sensitive information on a shared device. No records are sent automatically.

OLD ALL-NIGHT ORGANISER
The original all-night checklist items and registers have been incorporated

can migrate the old JCRGM_ALL_NIGHT_ORGANISER browser save if accessible under
the same browser origin. It does not remove the original saved copy. Review
programme dates and new tasks after import. Changing file paths or browsers
may make the previous browser save inaccessible.

OFFLINE USE AND PREVIEW LIMITS
The preparations page embeds its logo, styles, scripts, icons, fonts and PDF
library. The preparation tools and PDF creation work offline in a current browser.
Other church-page shortcuts require their corresponding HTML files beside it.
A chat preview may block printing, downloads, confirmation dialogs or browser
storage. For full use, extract the ZIP and open index.html in Chrome, Edge,
Firefox or another current browser, or upload the two HTML files to your site.
