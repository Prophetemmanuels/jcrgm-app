JCRGM — Permits & Invitations
============================

INSTALL
1. Back up your existing index.html.
2. Copy BOTH index.html and permits-invitations.html into the SAME folder
   as your current church website pages. Replace the old index.html.
3. Open index.html and select Permits & Invitations in Membership & Administration.

The index retains the original uploaded content and navigation. This package
contains only the updated index and the new letters page; keep your other
existing website files in place.

USE
- Select Police permits or Invitations.
- Confirm the church contact details and enter the church address.
- Enter the recipient, programme, venue, dates and signatory details.
- Select Generate letter. Review every name, date and commitment.
- Optional: expand Edit generated wording, change it, then select Apply wording changes.
- Select Download PDF for a direct PDF file, or Print for the print dialog.
- For printing: A4, 100% scale, no browser headers or footers.
- Print and sign before submitting. Letters are never sent automatically.

The original church logo, fonts and PDF-generation library are embedded in
the new letters page. It needs no internet connection and supports multi-page letters.
The other index features and their existing dependencies are unchanged.

Police letters are REQUESTS / NOTIFICATIONS, not granted permits. Check the
correct procedure, office and notice period with your local police station.

DRAFTS
Save draft stores the current form and wording in this browser on this device.
Load draft restores it. Delete saved draft removes the saved copy. Saving is
manual, not automatic. Avoid saving personal details on a shared device.
If local storage is blocked, the generator still works without saved drafts.

VIEWER LIMITATIONS
A chat preview may block navigation, printing, local storage or downloads.
Extract this ZIP and open index.html in Chrome, Edge, Firefox or another current
browser for full functionality, or upload both HTML files to your existing site.

TECHNICAL
PDFs use embedded DejaVu Sans fonts and selectable text. The SVG preview, printed
pages and direct PDFs share the same page layout. Latin-script correspondence
is supported; complex-script shaping and emoji are not guaranteed.
jsPDF and font licenses are included under licenses/.
